# CodeQL Organization Miner

Herramienta de automatización en Python para realizar análisis estático de vulnerabilidades mediante CodeQL CLI sobre repositorios de GitHub pertenecientes a una organización.

## Requisitos
- Python 3.10+
- Git
- CodeQL CLI en el PATH

## Instalación
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
